## Quick start

```bash
git clone https://github.com/Active-Learning-Kyle/spidie-avatar.git
```

No build step, no dependencies — the PNGs are ready to use as profile pictures anywhere: GitHub, Discord, X, you name it.

## Set up your own Muse

Three steps, about two minutes. Full copy-paste prompts live in [`PROMPTS.md`](PROMPTS.md):

1. **Avatar** — send your Muse `image.png` (or any pose) and say "change your avatar to look like this". Animated variants (idle, working, …) generate automatically after the avatar is set.
2. **Name** — tell your Muse "your name is Spidie from now on".
3. **Pose** — send a pose PNG and say "change your avatar to this pose, keeping the same character".
