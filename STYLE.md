# Spidie style constraints

Every custom character generated through this project must match the reference avatar (`image.png`) in body proportions and art style. This is the hard constraint that keeps the whole set looking like one family. Only the character's identity, outfit, colors, and pose vary.

## Proportions (do not change)

- Chibi build: oversized round head, roughly 45–55% of the total figure height
- Whole figure about 2 heads tall
- Short, stubby arms and legs
- Full-body, centered composition

## Art style (do not change)

- Soft 3D collectible vinyl-figure look, smooth matte surfaces
- Large expressive eyes
- Clean plain white background
- Cute, chill vibe

## Reference

`image.png` is the canonical reference — pass it as the style-reference image on every generation. `SKILL.md` (Mode 2) shows exactly how to wire it into the prompt.
